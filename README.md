# 차근차근 — 병원 방문 준비

혼자 병원에 가는 사람이 예약 시각을 기준으로 준비 시작 및 출발 시각을 계산하고 준비항목을 확인하는 단일 HTML 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치, 서버, 로그인, 외부 통신이 필요하지 않습니다.

## 기능

- 처음 방문 / 다시 방문 / 검사·시술 상황 선택
- 예약 시각과 이동·여유·준비 시간을 사용한 준비표 계산
- 전날 및 그 이전에 출발하거나 준비해야 할 때 날짜 상대 표시
- 필수 체크리스트 4개와 진행도, 인쇄 / PDF 저장
- 모바일 화면과 잘못된 입력에 대한 안내

입력 값과 체크 상태는 저장하거나 전송하지 않습니다. 새로고침하면 초기화됩니다.
